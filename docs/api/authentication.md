# Authentication API

Authentication endpoints for EclipseLink AI.

See [eclipse-ai-part4a-api-auth.md](../../eclipse-ai-part4a-api-auth.md) for complete documentation.

## Endpoints

### POST /api/v1/auth/register
Register a new user account.

### POST /api/v1/auth/login
Login with email and password.

### POST /api/v1/auth/logout
Logout and invalidate session.

### POST /api/v1/auth/refresh
Refresh access token.

### GET /api/v1/auth/me
Get current user information.

For detailed request/response formats, see the main API documentation.
